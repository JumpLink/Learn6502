# Architecture Decision Records

Decisions that change the repo's package layout or a workspace invariant. One file per decision,
`NNNN-<slug>.md`, in the format gjsify uses: `Status` / `Context` / `Decision` / `Consequences`,
plus what is still open. Statuses: `Proposed`, `Accepted`, `Superseded by NNNN`, `Rejected`.
Only the maintainer sets `Accepted`.
