# Datenschutzerklärung

Learn 6502 Assembly (Learn6502) ist eine freie App zum Lernen von 6502-Assembler. Diese Erklärung gilt für die GNOME-App, die Web-App, die Android-App und die Windows- und macOS-Builds.

**Kontakt:** Pascal Garber, JumpLink, pascal@jumplink.eu. Die Postanschrift steht im [Impressum](../legal-notice/).

## Wir sammeln nichts

Die App hat keine Konten, keine Werbung, keine Analyse und keine Absturzberichte. Sie baut von sich aus keine Netzwerkverbindungen auf und sendet nichts an den Autor oder an andere. Die GNOME-App (Flatpak) hat gar keinen Netzwerkzugriff.

## Links

Einige Schaltflächen öffnen eine Webseite in Ihrem Browser: GitHub, die Spendenseite und „Teilen“, das ein vorausgefülltes GitHub-Issue öffnet. Erst wenn Sie dort selbst etwas absenden, wird etwas übertragen. Danach gelten die Regeln von GitHub bzw. des jeweiligen Anbieters.

## Was auf Ihrem Gerät gespeichert wird

Die App speichert Ihre Einstellungen und die Programme, die Sie selbst als Datei speichern. Unter Android gehört zu den Einstellungen auch der Code im Editor. Wenn Sie das System-Backup von Android nutzen, kann es diese Daten mitsichern. Die Web-App speichert keine Einstellungen und berührt nur Dateien, die Sie selbst speichern oder öffnen.

## Andere Anbieter

Flathub, App-Stores und GitHub-Releases, über die Sie die App beziehen können, haben eigene Datenschutzregeln.
