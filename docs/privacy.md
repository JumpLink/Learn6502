# Privacy statement

Learn 6502 Assembly (Learn6502) is a free app for learning 6502 assembly. This statement covers the GNOME app, the web app, the Android app and the Windows and macOS builds.

**Contact:** Pascal Garber, JumpLink, pascal@jumplink.eu. The postal address is in the [legal notice](../legal-notice/).

## We collect nothing

The app has no accounts, no advertising, no analytics and no crash reporting. It makes no network connections by itself and sends nothing to the author or to anyone else. The GNOME app (Flatpak) has no network access at all.

## Links

Some buttons open a web page in your browser: GitHub, the donation page, and "Share", which opens a pre-filled GitHub issue. Nothing is sent until you submit something there yourself. After that, the rules of GitHub or of the respective provider apply.

## What is stored on your device

The app stores your settings and the programs you save as files yourself. On Android, the settings include the code in the editor. If you use Android's system backup, it may include this data. The web app stores no settings and only touches files you save or open yourself.

## Other providers

Flathub, app stores and GitHub releases, where you may get the app, have their own privacy policies.
