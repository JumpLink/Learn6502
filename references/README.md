# Code References

External Git submodules for **inspiration and best practices** in development.

## NativeScript References

- **[oss-weather](https://github.com/Akylas/oss-weather)** - Weather app (Svelte + TypeScript, Material Design)
- **[ui-material-components](https://github.com/nativescript-community/ui-material-components)** - Material Design plugins monorepo (MD2 & MD3)
- **[conty](https://github.com/Akylas/conty)** - Interactive stories app (offline functionality)
- **[alpimaps](https://github.com/Akylas/alpimaps)** - Offline maps app (geodata processing)
- **[nativescript](https://github.com/NativeScript/NativeScript)** - NativeScript core framework (to understand how NativeScript itself works, including available utils in `packages/core/utils/`)
- **[nativescript-app-utils](https://github.com/nativescript-community/nativescript-app-utils)** - App utilities and helpers
- **[systemui](https://github.com/nativescript-community/systemui)** - System UI integration utilities

## Maintenance

```bash
git submodule update --remote --recursive
```
